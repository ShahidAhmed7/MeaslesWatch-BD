# Case-inspection plan

Declared during generation, before the completed recovered scorecard is available.
The purposive subset is EXT-01, EXT-06, EXT-09, EXT-10, EXT-15, EXT-18, EXT-26 and
EXT-30. It spans category/date scope, arithmetic denominators, outbreak definition,
causal identification, infant denominators, unavailable-versus-zero interpretation,
suppression and conflicting source windows. It is not a random sample or a separate
estimate of benchmark accuracy. EXT-06 also provides a long-reasoning example.

For each item inspect the frozen question, original supporting passages, independent
gold, A/B/C structured answers, source scopes, citation locators and unverified
summary prose. Record concrete residual errors and limitations, including correct
numbers with wrong metadata. Preserve all programmatic verdicts. Do not change
questions, adapters, prompts, gold, tolerances or grading after this inspection.

This is an AI-conducted qualitative inspection, not blinded external human
adjudication. It complements automated scoring; it does not make every unchecked
sentence true or establish a universal verifier.
